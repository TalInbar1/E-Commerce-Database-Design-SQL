# E-Commerce Data Infrastructure & Analytics Project
## SQL Database Design & Business Intelligence

### Project Overview
This project involves the end-to-end design and implementation of a relational database for an E-commerce platform. From initial requirement analysis to building a functional SQL database and visualizing key business metrics using Power BI.

### Tech Stack:
* **SQL:** Database schema creation (DDL), complex queries (DML), and data manipulation.
* **Power BI:** Developing interactive dashboards for business insights.
* **Data Modeling:** Designing ERD (Entity Relationship Diagrams) and normalization.

### Key Contributions:
* **Database Architecture:** Built a robust schema including tables for Orders, Inventory, Users, and Transactions.
* **Advanced Queries:** Implemented complex SQL scripts to analyze sales performance, customer behavior, and inventory levels.
* **Visual Analytics:** Created a Power BI dashboard to track KPIs, identifying trends and operational bottlenecks.

### How to use:
1. The full SQL script can be found in `Database_Schema_and_Queries.sql`.
2. The visual reports are available in the `Business_Insights_Dashboard.pbix` file.
